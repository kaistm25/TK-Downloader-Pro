## 🌍 العربية

### 📥 نظرة عامة

**TK Downloader Pro** هو برنامج تحميل شامل يدعم أكثر من **25 منصة** لتحميل الفيديوهات والملفات والبرامج وروابط Torrent بواجهة عصرية.

### ✨ الميزات الرئيسية

- 🌐 **دعم متعدد المنصات**: YouTube, Facebook, Instagram, TikTok, Twitter/X, Vimeo, Dailymotion, Twitch, Spotify, SoundCloud وأكثر من 1000 موقع آخر (عبر yt-dlp)
- 🎵 **تحميل الصوت فقط** (MP3) من أي فيديو
- 🌀 **دعم Torrents** (Magnet links وملفات .torrent)
- 📥 **تحميل جماعي** — قائمة روابط دفعة واحدة
- 🔁 **التحميل التسلسلي** — واحداً تلو الآخر مع ترتيب قابل للتعديل
- ⏸️ **إيقاف/استئناف** أي تحميل
- 🔄 **استئناف تلقائي** للتحميلات المنقطعة
- 🍪 **دعم كوكيز المتصفح** لتجاوز القيود
- 📜 **سجل التحميلات** مع تفاصيل كاملة
- 🌐 **خادم LAN** — أرسل روابط من أي جهاز على شبكتك المحلية
- 🧩 **إضافة متصفح** لإرسال الروابط مباشرة
- 🎨 **واجهة عصرية** مع ثيم داكن ووضع مضغوط
- 🔒 **منع السكون** أثناء التحميل

### 🚀 التثبيت السريع

#### المتطلبات

- Python 3.8 أو أحدث
- FFmpeg (لاستخراج الصوت)
- Windows / Linux / macOS
